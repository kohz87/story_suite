# Studio build docs

The plan for the new pack Studio, kept here so remote build sessions can read it.

- `studio-plan.md`: the Studio plan (model, screens, parts, export rules). The Studio uses the current Story Suite design (mock v7, Glass v5).
- `studio-jobs.md`: the job table (lanes, files, tests, order). One job per session; each job owns only its own files.
- `mocks/`: screenshots of the drawn mocks (MK-1 record page, MK-6 pairing, MK-9 start and convert), at 390 and 1280, dark and light. Editor screens match them.

Paths in these docs that start with `scratch/` are the lead's local working files, not in the repo.
