# Ersveil (open world): conversion notes (pack format 3 → 4)

Written by `scripts/packs/convert-3to4.mjs` from `examples/packs/ersveil-world/pack.json`. The world pack is `ersveil` 4.0.0 (`pack.json`); the game pack is `ersveil-game` 1.0.0 ("Ersveil rules", `game.json` in the zip, `examples/packs/ersveil-game/pack.json` in the repo). Do not edit this file by hand: run the script again.
